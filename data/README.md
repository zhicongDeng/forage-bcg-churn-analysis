# Data

The datasets used in this project are provided by the [BCG Data Science & Analytics Virtual Experience Program](https://www.theforage.com/simulations/bcg/data-science-ccdz) on Forage.

Place the following CSV files in this directory before running the notebooks:

| File | Description |
|------|-------------|
| `client_data.csv` | Customer information (14,606 rows, 26 columns) — includes consumption, contract dates, forecasts, margins, and churn labels |
| `price_data.csv` | Monthly energy prices per customer (193,002 rows, 8 columns) — off-peak, peak, and mid-peak prices (variable and fixed) |

## Intermediate files

The following files are generated by the notebooks:

| File | Generated by | Description |
|------|-------------|-------------|
| `clean_data_after_eda.csv` | `eda.ipynb` | Cleaned dataset with price variance features |
| `my_data_for_prediction.csv` | `feature_engineering.ipynb` | Final feature-engineered dataset for modeling |
